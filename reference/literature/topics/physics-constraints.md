# 物理引导与物理约束机器学习

本主题对应元数据文件 `reference/literature/metadata/physics-constraints.yaml`。入选标准不是是否出现“physics-informed”字样，而是论文是否给出可迁移到公里尺度天气时空超分辨的约束机制，或能直接改变本项目对照实验与评估设计。泛泛的天气神经网络和与重建无关的 PINN 应用未纳入。

## 范围与问题

本项目要从低空间分辨率、低时间采样频率的序列重建同一时段内更细、更密的天气场。记低分辨率输入为 \(x\)，生成的高时空分辨率场为 \(\hat y\)，已知的粗化或观测算子为 \(D\)，离散动力方程残差为 \(R\)。入选文献覆盖四类本质不同的做法：

1. **训练期软约束**：把 \(\lVert R(\hat y)\rVert^2\) 加入损失，让数据误差和物理误差共同优化；PINN、MeshfreeFlowNet、PhyDL-NWP 和 PIDM 属此路线。
2. **结构硬约束**：通过输出层或变量重参数化，使 \(D(\hat y)=x\)、守恒关系或变量间不等式在浮点精度内成立；Beucler、Geiss、Harder 和 González-Abad 属此路线。
3. **生成采样期约束**：在 score-based 逆向采样中插入残差校正，主模型训练目标可以不变；CoCoGen 是代表。
4. **混合数值—学习模型**：保留可微动力求解器，把未解析过程交给网络，并通过多步积分端到端训练；NeuralGCM 是代表。

这里必须区分三种“好”：**满足约束**、**降低 PDE 残差**和**更接近真实天气**。三者并不等价。粗网格总量正确并不限定细网格分布；离散残差小可能来自方程、差分格式或自由参数化对误差的吸收；物理合理的样本仍可能落在错误的天气状态附近。对生成模型还应区分**每个样本**和**集合均值**：只对均值守恒，不代表集合成员守恒。

## 方法演进脉络

**2019：从“数据拟合”到“方程参与优化”。** PINN 把 \(u(t,x)\) 表示为可微函数，在配点上惩罚方程残差；同时给出离散时间隐式高阶积分构造。这为后来的连续场重建提供了两个分支：一路直接对时空坐标求导，另一路把已知时间积分结构嵌入网络。

**2020–2021：约束进入时空超分辨和网络结构。** MeshfreeFlowNet 把坐标网络扩展成“低分辨率时空上下文编码器 + 连续解码器”，直接面向空间和时间同时增密。Beucler 等则说明，物理关系不一定只能作为损失：把部分输出写成其余输出和输入的解析残差，可以让守恒在每次前向传播后成立。由此形成沿用至今的软/硬两条路线。

**2023–2024：硬约束从单变量总量扩展到真实降尺度和多变量关系。** Geiss 的 DE 层把“生成场回降采样必须复现输入”变成精确定义；Harder 等系统比较多种分配/校正层，并加入时空超分辨、湿静能和真实 WRF 粗细网格实验。González-Abad 等进一步指出，多变量联合建模本身不是保证，必须通过输出参数化排除变量间矛盾。

**2024：从外加惩罚走向求解器内部耦合。** NeuralGCM 不让网络独立预测整个状态，而让可微动力核心负责已解析运动，网络只给出未解析物理倾向，并沿多步积分反向传播。这把“物理约束”从事后诊断转化为模型的时间推进结构，也把评估从单步 RMSE 扩展到稳定性、集合校准和气候漂移。

**2025：扩散模型出现训练期与采样期两条物理化路径。** CoCoGen 在采样过程中做残差校正，强调冻结主模型后的复用；PIDM 把残差虚拟似然写入训练目标，强调推理不改变。PhyDL-NWP 则面向真实天气方程不完整的问题，以显式项库加潜在力补足缺失过程。三者共同说明，近期重点已不是简单地“加一个物理损失”，而是决定物理在**训练、采样还是状态推进**中起作用，以及如何处理不完备方程。

这条脉络不是新路线替代旧路线。硬粗化约束、软动力残差和混合求解器约束的是不同对象，可以组合；采样期校正与训练期 PIDM 则应作为计算预算和泛化能力不同的独立方案比较。

## 跨论文综合

### 约束对象比“软或硬”的标签更重要

文献中的约束至少有三个层级：

- **观测/粗化一致性**：\(D(\hat y)=x\)。它限定高分辨率解所在的相容集合，是降尺度特有的最强先验，但不决定集合内的小尺度结构。
- **状态与变量间关系**：质量、能量、非负性或温度排序。它们可以逐样本精确成立，却仍可能与动力演化不一致。
- **动力一致性**：\(R(\hat y,\partial_t\hat y,\nabla\hat y)=0\)。它能连接相邻时刻和空间导数，但最依赖方程完整性、差分格式、边界和次网格闭合。

因此，一个 CorrDiff+CfC 模型可以完全守恒粗网格水量，却生成静止不变的错误细节；也可以 PDE 残差下降，却因为自由潜在力变大而失去可解释性。实验报告必须分别给出三类诊断，不能用单一“physics score”代替。

### 软约束的优势是容许近似，硬约束的优势是提供可检验保证

软约束适合方程本身近似、含噪声或缺项的天气场景，但权重是数据拟合与物理拟合之间的显式折中。MeshfreeFlowNet 的大权重退化、PIDM 对噪声步相关方差和超参数扫描的讨论，都说明固定一个任意 \(\lambda\) 不足以得出结论。硬约束消除了权重调参并给出逐样本保证，但保证只覆盖写入架构的那条关系；若粗化核、面积权重或变量定义写错，它会把错误关系精确地强加给输出。

真实数据常处于两者之间。Harder 等的 WRF 粗细模拟只近似满足约束，而 Geiss 明确展示了平均池化假设遇到双三次数据时的错配。因此，项目应先测量原始 LR/HR 对的约束违反，再决定采用精确硬层、带容差的软项，还是修正粗化算子，而不是默认“硬的一定更好”。

### 生成模型需要同时看样本物理性和分布校准

CoCoGen 与 PIDM 的差别不只是约束施加时机。前者保留预训练模型，增加采样期 PDE 算子评估和收敛参数；后者把成本移到训练期，推理不变，但可能改变学习到的数据分布。两者都可能降低残差而不改善 CRPS、极端事件或谱分布，甚至通过过度校正减少合理的小尺度多样性。

CorrDiff 的任务是条件分布重建，不能只展示一张残差最小的样本。物理损失是否改善集合均值、单成员锐度、成员间离散度和排名评分，应分别评估；所有硬约束也应施加于每个成员，再计算集合统计。

### 连续坐标或 CfC 本身不等于时间物理

MeshfreeFlowNet 和 PhyDL-NWP 表明，任意时间坐标查询提供了方便的表示与微分接口，但“能查询”并不证明中间时刻动力正确。PhyDL-NWP 尤其提供了清晰反例：方法允许时间降尺度，实验却只验证空间降尺度。CoCoGen 的 Burgers 实验一次生成整段轨迹，避免窗口内逐步误差传播；NeuralGCM 则通过多步展开让学习和动力在积分中相互适应。两者代表“整段重建”和“逐步推进”两种时间归纳偏置。

本项目是从已有时段两端或稀疏帧重建中间状态，而非自由预报。CfC 更适合表达整段连续时间依赖、时间边界条件和动力残差，不应无依据地采用自回归 rollout 来制造额外误差；同时应设置独立逐帧 CorrDiff 对照，证明收益确来自时间建模而非参数增加。

### 现有证据呈现明显的场景断层

理想 PDE 基准便于隔离机制，真实天气数据才暴露粗化错配、未解析过程和分布外泛化问题。守恒和残差改善通常最容易证明，跨年份、跨倍率、极端天气和集合校准的证据更少。即使 NeuralGCM 展示了长期稳定性，其全球粗分辨率预报也不能代替公里尺度区域重建验证。对本项目最合理的迁移方式是复用机制和实验逻辑，而不是继承论文中的性能承诺。

## 对本项目的启示

### 模型设计

1. **先做可插拔的粗网格一致性层。** 在物理单位下定义与 CWA 数据生成过程一致的 \(D\)，对每个回归输出和每个扩散样本施加 \(D(\hat y)=x\)。非负且需要保持总量的变量可比较 SmCL 式比例分配与加法式校正；有正负号的场优先比较加法式校正。记录校正值 \(\lVert\hat y_{raw}-\hat y_{corr}\rVert\)，防止网络完全依赖最后修正。
2. **把软约束拆成粗化一致性和动力残差两项。** 前者直接监督 \(D(\hat y)-x\)，后者在时间维连接 CfC 输出。坐标连续解码可用自动微分，固定网格的 CorrDiff 输出可用与数据分辨率一致的有限差分；两者不能混用导数定义而不做对照。
3. **参考 PIDM 在预测的干净场上计算扩散物理损失。** 对 CorrDiff 的 EDM 参数化先实现小范围权重与噪声区间扫描，再与采样期 CoCoGen 式少量校正比较。第一版不必同时实现两条路线，但实验设计应区分训练开销和采样开销。
4. **谨慎引入潜在力。** 若大气方程缺少摩擦、垂直速度或次网格项，PhyDL-NWP 的潜在力比强迫零残差更现实；但应限制容量、做正则化并报告其方差解释比例，否则“物理残差降低”可能只是自由拟合项变大。
5. **仅在变量定义支持时加入多变量硬关系。** 可从非负性、变量排序或显式水量/能量关系开始，不因多通道联合生成就假定一致。NeuralGCM 式动力核心耦合留作后续独立研究分支，不宜与首轮约束消融同时改变整个系统。

### 对照实验

建议保持数据划分、CorrDiff 主干、CfC 配置、训练预算和随机种子一致，至少设置：

| 组别 | 时间模型 | 粗化一致性 | 动力约束 | 目的 |
|---|---|---|---|---|
| A | 无 CfC，逐帧 CorrDiff | 无 | 无 | 原有空间基线 |
| B | CorrDiff+CfC | 无 | 无 | 隔离时间建模收益 |
| C | 同 B | 软损失 | 无 | 测量近似一致性正则化 |
| D | 同 B | 硬输出层 | 无 | 测量精确保证及其代价 |
| E | 同 B | 无 | PDE 残差软损失 | 隔离时间动力约束 |
| F | 同 B | 硬输出层 | PDE 残差软损失 | 检验两类约束是否互补 |

- 对 C、E、F 的物理权重使用跨数量级扫描，并报告数据项与物理项梯度或量值尺度；只报“最佳权重”会隐藏训练不稳定性。
- 对 D、F 使用相同约束层比较不同变量，避免把降水非负分配、温度粗化一致性和能量守恒混为一种操作。
- 另设**采样期校正**和**PIDM 式训练**小规模对照，固定生成步数与物理算子调用预算；不要与首轮 A–F 的主结果混在一起。
- 用空间 2×/4×、不同时间间隔和留出的年份/天气型做分布外测试。若训练粗化是平均池化，另用独立粗细模拟或不同粗化核测试算子错配敏感性。

### 评估指标

- **精度与感知质量**：分变量 RMSE、MAE、MS-SSIM，并给出空间功率谱和极端分位数误差；不能只用全场平均 RMSE。
- **物理一致性**：逐样本 \(\lVert D(\hat y)-x\rVert\)、负值比例/负值总量、变量间关系违反率，以及按变量和量纲归一化的 PDE 残差。全部在反标准化后的物理单位中计算，并使用区域网格面积权重。
- **时间与细尺度结构**：中间时刻误差随时间位置的变化、时间导数/倾向误差、动能或水量等诊断量、谱随提前时间或重建间隔的漂移。借鉴 MeshfreeFlowNet，物理量应同时报告 NMAE 或 \(R^2\)，不能只报告生成残差。
- **概率质量**：集合 CRPS、spread–skill ratio 和成员功率谱；硬约束前后均按成员计算，再检查集合均值，避免平滑均值造成虚假改善。
- **稳健性与成本**：OOD 年份和天气型、不同空间/时间倍率、边界与棋盘格伪影、约束校正幅度、训练时间、采样时间及 PDE 算子调用次数。
- **失败分析**：分别列出“精度升/残差升”“精度降/残差降”“守恒满足但极端变差”等组合，以识别错误方程、过强校正和集合多样性损失。

## 优先阅读顺序

1. **harder-2023-climate-downscaling**：最贴近本项目的硬约束、变量、时空任务和评价组合，先读方法与实验设计。
2. **jiang-2020-meshfreeflownet**：理解连续时空编码—解码和 PDE 损失如何共同工作，以及物理指标为何不能只用一个 RMSE。
3. **bastek-2025-physics-diffusion**：直接对应 CorrDiff 改造，重点看残差虚拟似然、x0 估计和噪声步权重。
4. **geiss-2023-conservation**：DE 层推导短而可实现，适合率先做守恒输出层和粗化算子错配实验。
5. **beucler-2021-analytic-constraints**：建立软/硬约束的统一代数视角，并理解守恒与泛化之间的边界。
6. **luo-2025-phydl-nwp**：面向真实天气的不完整方程处理与连续坐标表示，重点批判性阅读时间降尺度证据和潜在力设计。
7. **jacobsen-2025-cocogen**：在实现采样期引导前阅读，重点比较概率流 ODE、校正步数和稀疏观测条件。
8. **raissi-2019-physics-informed**：回溯连续/离散时间 PINN 的原始定义，为自动微分和时间积分方案补基础。
9. **gonzalez-abad-2024-multivariable**：篇幅短，适合在设计多变量输出层时集中查阅。
10. **kochkov-2024-neuralgcm**：作为长期混合数值—学习路线阅读，先看模型结构和多步在线训练，不必在首轮复现整个系统。
