# 天气与物理场的时空架构

## 范围与问题

本主题研究**如何在空间、时间和尺度三个轴上表示并更新天气场或其他物理场**，覆盖卷积递归网络、时空 Transformer、神经算子、图网络与多尺度建模。选文既包括 ConvLSTM 这类奠基结构，也包括 FNO、MeshGraphNets 等物理场建模范式，以及 Earthformer、FourCastNet、GraphCast 等天气应用中的关键演进。扩散、GAN 和生成式集合预报不在本主题范围内；这里只讨论它们可能使用的确定性骨干、条件编码或物理约束接口。

对本项目，输入是低空间分辨率、低时间采样频率的多变量序列，目标是重建同一时段内更高时空分辨率的天气场。这与多数论文的“由过去等间隔帧预测未来帧”并不相同：

- **预测不等于重建**：下一时刻预报误差包含不可预知的未来信息，而时段内重建还要利用后续观测，并处理双向时间条件。
- **算子跨网格不等于真实超分辨**：FNO 的零样本分辨率迁移说明函数表示可跨离散网格求值，不证明能恢复低分辨率输入中已丢失的天气尺度。
- **全球中期预报不等于公里尺度区域重建**：FourCastNet、GraphCast 主要证明大规模架构和训练策略有效，不能把小尺度技巧直接外推到本任务。

因此，下文把每篇工作拆成四个可比较部件：**时间状态更新、空间信息混合、尺度桥接、训练与评价目标**。入选的 10 篇分别在这些部件上提供不可替代的基线或设计依据，而非仅按引用量罗列。

## 方法演进脉络

### 1. 从“把图像展开成向量”到结构化的时空状态

ConvLSTM 的关键不是简单地把卷积和 LSTM 拼接，而是让输入、隐状态、门控和状态转移都保留网格拓扑。PredRNN 随后指出，单一细胞状态不足以区分跨层空间表征和跨时间动态，因此引入两条记忆流。对本项目而言，这两篇构成最必要的离散递归对照：如果 CfC 不能在相同空间骨干、参数量和训练预算下超过它们，复杂连续时间机制的增益就尚未被证明。

### 2. 从通用状态到物理动态与未知残差的分工

PhyDNet 将“可由微分动态解释的变化”与外观、纹理等未知变化分开。相较只把物理损失加到总目标，这一路线改变的是**状态更新的职责分配**：物理分支提供可约束的低维动态，残差分支补足未建模过程。它因此成为物理增强 CfC 的直接结构前身，但其微分滤波器仍是学习得到的通用先验，距离真实大气热力学和守恒约束还有明显距离。

### 3. 从局部卷积到函数空间与网格空间的全局传播

FNO 把空间混合提升为函数空间算子，在频域学习全局积分核；MeshGraphNets 则在可变形、非规则网格上以消息传递学习局部相互作用。两者代表两种不同的离散观：前者追求跨规则网格的一致函数表示，后者追求几何和分辨率的适应性。FourCastNet 的 AFNO 和 GraphCast 的多尺度二十面体网格分别把这两条路线推进到全球天气尺度。

### 4. 从串行递归到分块注意力和可并行时间混合

SimVP 首先用极简 CNN 说明许多增益可能来自空间编码/解码和训练协议，而不是递归单元本身。Earthformer 用 Cuboid Attention 联合处理局部时空窗口，再以全局向量沟通天气背景；TAU 则把帧内静态注意力和帧间动态注意力分解，使时间模块可并行。CfC 的定位应放在这条效率轴上：它是否以更小的状态、更少的串行步骤，换取更好的长时间依赖和非均匀采样适应性，而不是只比较最终 MSE。

## 跨论文综合

### 没有单一架构同时解决三个轴

十篇工作实际上形成了互补而非替代关系。ConvLSTM/PredRNN/TAU 主要回答“状态如何随时间更新”；FNO/Earthformer/GraphCast 主要回答“空间信息以何种范围传播”；SimVP 的多尺度 CNN、GraphCast 的多网格和 FNO 的函数表示才触及“尺度如何连接”。因此，把 CfC 直接替换整个天气骨干通常不公平：更合理的是在统一多尺度空间编码器中替换时间核心，同时单独消融全局空间混合和上采样器。

### 局部归纳偏置与全局混合需要按尺度组合

卷积递归擅长局地平移和短程输运，但深层堆叠才能扩大感受野；全局注意力和频域算子能快速传播大尺度信息，却可能平滑局地极值或带来较高显存开销；图网络提供介于两者之间的稀疏多尺度路径。一个符合天气多尺度特性的结构应是：**局地网格状态负责细节，稀疏长程边/全局向量/低频通道负责天气背景，CfC 负责在连续时间上整合这些状态**。这三者需要用替换实验区分贡献，不能一次性堆叠后只报告总分。

### 物理增强的核心是避免“重复建模”和“错误约束”

PhyDNet 的价值在于物理分支与残差分支互补；FNO、MeshGraphNets 则表明离散形式本身也是物理先验。但若把完整、刚性的大气方程强加于仅含少量区域变量的数据，未观测强迫、地形和次网格过程会使约束产生系统偏差。更稳妥的做法是从可检查的局部性质入手，例如非负降水、合理时间变化率、质量/水量残差或平滑守恒倾向，并让数据驱动残差保留修正能力；硬约束与软惩罚必须分别消融。

### 分辨率泛化、细节真实性和滚动稳定性是不同问题

FNO 的跨分辨率误差、MeshGraphNets 的跨网格 rollout、GraphCast 的多步中期技能分别测量不同性质，不能合并成“支持超分辨”。特别是 MSE/RMSE 会偏爱条件均值和较平滑场；GraphCast 原文专门分析最优模糊以排除评分仅来自平滑的可能性，Earthformer 也明确承认小尺度模糊。因此本项目必须同时测量网格点误差、空间功率谱和时间差分，且把“从粗场恢复细节”与“把已有解放到更细网格”分开报告。

### 论文中的 SOTA 数字不能直接横向排序

这些论文的数据变量、区域、预测时长、真值来源和基线实现都不同。FourCastNet 与 GraphCast 的全球 ACC/RMSE 不应和 SEVIR 的 CSI 或视频 SSIM 放在同一排行榜；同一指标也会受归一化、纬度权重、降水阈值和滚动步数影响。可复用的是结构和评估问题，而不是脱离协议的分数。项目内所有架构对照必须共享时间切分、变量预处理、输入输出时刻、训练预算和真值。

## 对本项目设计、对照实验与评估的启示

### 建议的架构拆分

1. **统一条件编码器**：用多尺度 CNN 将低分辨率多变量历史和未来边界观测编码到潜空间；保留变量、地形、时间戳和掩码通道。
2. **可替换时间核心**：默认用 CfC 在潜空间传播状态，并以目标时刻或归一化时间差作为条件；对照为 ConvLSTM、PredRNN、TAU 和无递归的 SimVP 转换器。若要利用时段两端观测，应显式比较单向、前向后向及中间状态融合，不能默认未来预测结构适用。
3. **可替换空间混合器**：先以纯卷积为默认，再分别加入 FNO/AFNO 低频全局通道、Cuboid Attention 或稀疏图边。每次只改一个部件，以区分时间记忆和长程空间传播的收益。
4. **尺度解码与 CorrDiff 接口**：确定性解码器负责低频/平均场，CorrDiff 负责条件细尺度修正时，应分别保存并评估两阶段输出，判断误差来自时间轨迹还是空间细化。
5. **物理残差分支**：参考 PhyDNet 设“物理倾向 + 数据残差”，但只编码当前数据真正支持的约束。所有物理损失需报告权重敏感性及是否牺牲极端事件技巧。

### 最小而有判别力的对照矩阵

- **插值与持续性下界**：空间双三次/双线性插值、时间线性插值及最近观测；任何复杂模型都应先超过这一组。
- **同骨干时间核心消融**：ConvLSTM → PredRNN → TAU → CfC；PredRNN 可作为资源允许时的增强项，首要必做项是 ConvLSTM、SimVP 和 CfC。
- **全局空间混合消融**：卷积、FNO/AFNO、Cuboid Attention 三选一替换；图网络在地形感知或非规则网格阶段再引入，避免第一轮实验变量过多。
- **物理消融**：无物理、仅物理损失、物理/残差双分支三者比较；另测去掉时间差分正则，检验其是否与物理约束重复。
- **采样鲁棒性**：训练内时间间隔、未见时间间隔、不规则缺测和不同空间倍率分别测试。不要把训练内随机丢帧的结果称为连续时间外推。
- **公平预算**：同时报告参数量、显存、训练时耗、推理时耗和滚动/查询步数；CfC 的潜在优势应在精度—成本曲线上体现。

### 评估协议

- **点误差**：按变量和区域报告 MAE、RMSE，并同时给出去归一化后的物理单位；全球或大区域对照可使用纬度加权 ACC/RMSE。
- **降水与极端**：按多个强度阈值报告 CSI、POD、FAR，并按预报/重建超前量和季节分层；不能只报告全网格 MSE。
- **空间细节**：报告径向功率谱、谱误差、小尺度能量比和梯度/拉普拉斯误差，检查是否过平滑或产生虚假高频。
- **时间连续性**：在真实未参与条件化的目标时刻计算误差；另报告一阶时间差分误差、事件起止时间误差和相邻目标时刻抖动。
- **物理一致性**：按变量可行性检查非负性、范围、守恒残差及多变量关系；架构评价与物理真实性评价分开呈现。
- **泛化与稳定性**：固定按年份/时段切分训练、验证、测试，单独保留强天气过程；跨空间倍率与采样间隔实验使用相同测试事件。
- **真值意识**：再分析或雷达本身有偏差。GraphCast 排除 ERA5 总降水是重要警示，本项目需说明真值来源、观测/再分析不确定性和极端降水偏差，不把对真值的低误差等同于真实大气正确。

## 优先阅读顺序

1. **shi2015convlstm**：先明确格点时空状态及雷达评价的最小范式。
2. **gao2022simvp**：建立强而简单的统一编码—转换—解码基线，避免把骨干收益误归于 CfC。
3. **wang2017predrnn**：理解双记忆流，为设计 CfC 与多尺度特征的交互提供递归上界。
4. **tan2023tau**：比较并行时间注意力和连续递归，重点看差分正则与效率分析。
5. **leguen2020phydnet**：确定物理分支、残差分支和物理消融的实现边界。
6. **li2021fno**：掌握函数空间算子、零样本分辨率迁移的真实含义及其限制。
7. **gao2022earthformer**：学习如何控制时空注意力成本，以及为何需要全局天气背景。
8. **pfaff2021meshgraphnets**：在考虑地形图或非规则区域网格前阅读，重点看网格构建和 rollout 评价。
9. **pathak2022fourcastnet**：将 FNO 原理连接到多变量天气骨干和高分辨率计算预算。
10. **lam2023graphcast**：最后综合多尺度图、多步训练和严格业务对照，尤其关注模糊、频谱和降水真值限制。

若近期目标是尽快启动 CfC 对照，先读 1–5；若当前瓶颈是公里尺度显存和长程背景，再优先读 6–9；GraphCast 适合在制定最终天气评估协议时精读。
