# 扩散模型用于天气/气候降尺度与区域高分辨率生成

主题：`diffusion-downscaling`。本条目选取 10 篇代表作，元数据见 `reference/literature/metadata/diffusion-downscaling.yaml`，原文见 `reference/papers/diffusion-downscaling/`。核验日期为 2026-11-23。

## 范围与问题

本主题关注从粗分辨率天气/气候场生成细尺度区域场，即学习条件分布 \(p(X^{HR}\mid Y^{LR},S)\)，其中 \(S\) 可包含地形、海陆掩码、海表温度和时间条件。与确定性超分辨不同，核心不是寻找唯一逐像素最接近的场，而是同时恢复：

1. 输入已能约束的大尺度结构；
2. 输入不能完全确定的小尺度随机场及其集合不确定性；
3. 降水、强风、台风等分布尾部；
4. 对连续天气应用必不可少的跨时刻、跨变量和跨尺度物理一致性。

选文覆盖直接条件扩散、条件均值加残差扩散、潜空间扩散、视频扩散、跨模式偏差校正以及极端事件生成。通用 DDIM、蒸馏、consistency sampling 等高效采样方法不单独纳入；`hess-2025-scale-adaptive` 被保留是因为其非配对 ESM 降尺度、空间尺度控制和跨模式实验，而不是为了展开通用采样算法。纯临近预报、纯全球预报和非扩散 GAN 也只作为比较背景，不占本主题名额。

## 方法演进脉络

### 1. 从“生成合理细场”到显式条件分布

`addison-2022-local-scale` 在 2022 年将条件 score-based 扩散用于对流允许区域气候模式仿真。其重要性不只是换一个生成骨干，而是把降尺度从唯一映射改写为给定粗尺度环流后的多个可能细尺度实现。可学习位置特征也说明：粗动力场没有提供的稳定局地信息，可以由静态条件补足。同一团队后续把这一方向扩展为更完整的 [CPMGEM 长期、极端和跨 GCM 实验](https://arxiv.org/abs/2407.14158)，但本条目保留早期论文作为方法起点，避免同一研究线重复占位。

### 2. 残差分解成为多尺度训练的主线

直接条件 DPDM 仍从完整高分辨率场去噪；CorrDiff、STVD、LDM_res 和 TAUDiff 则先估计条件均值，再让扩散学习残差。四者的区别比共同点更有价值：

- CorrDiff 在**单时刻像素空间**做残差，重点是跨变量和雷达通道合成。
- STVD 把残差扩展为**整段联合随机序列**，时间依赖同时进入均值与残差。
- LDM_res 把残差压入 **VAE 潜空间**，以重构误差上限换取去噪计算可行性。
- TAUDiff 把重时间建模放在**确定性均值模块**，扩散模块较小，突出极端集合生成成本。

因此，“残差扩散”不是单一架构，而是把大尺度可预测性和小尺度不确定性分配给不同模块的归纳偏置。

### 3. 从配对完美模式实验走向偏差校正和跨域迁移

真实粗分辨率输入并不总是高分辨率目标的平滑版本。CorrDiff 和 DiffScaler 使用独立粗再分析与区域动力降尺度目标，任务已包含空间配准、局地通道合成和模式差异；Hess 与 Aich 进一步面对自由运行 ESM 和历史观测不逐时配对的问题。前者以无条件生成分布配合尺度可控加噪，后者先构造共享嵌入再学习条件逆映射。这两条线共同把问题从图像超分辨推进到“哪些大尺度应信任、哪些尺度应重采样”的可控统计校正。

### 4. 从区域快照到视频、物理约束和全球公里尺度

STVD 与 TAUDiff 分别代表联合视频扩散和时序均值加轻量校正；cBottle 则用球面网格、级联生成和局部 patch 去噪把空间规模推到全球约 5 km。Addison、DPDM、Hess、Aich 和 cBottle 对极端事件的关注也从分位数匹配，扩展到重现期、气候情景趋势和按位置引导热带气旋。需要强调：空间规模的增长并不自动带来时间因果性，极端“看起来真实”也不等于风险分布校准。

## 跨论文综合

### 残差化降低学习难度，但不消除概率和物理误差

CorrDiff 的方差分解解释了为何残差比完整场更易学习；STVD 和 LDM_res 的消融进一步支持这一点。然而 CorrDiff 仍欠离散，DPDM 反而偏过离散，说明残差参数化与集合校准是两个问题。类似地，集合平均常改善 MAE/RMSE，却可能重新抹平扩散试图恢复的小尺度方差；`merizzi-2024-wind-speed` 的集合均值优势不能替代单成员谱、CRPS 和 rank histogram。

### 输入与目标的构造决定实验难度，分辨率数字本身不可直接横比

至少有三类任务必须分开报告：

1. **自粗化超分辨**：由同一高分辨率场面积平均、低通或插值得到输入。STVD 和 TAUDiff 的部分实验属于此类，大小尺度严格配对，主要考验缺失谱恢复。
2. **独立产品间降尺度**：ERA5 与 WRF/COSMO/CERRA 来自不同模拟或资料同化过程。CorrDiff、DPDM、DiffScaler 和 Merizzi 更接近这一设置，需要同时处理系统差异。
3. **非配对模式校正**：自由运行 ESM 与观测没有逐时刻真值。Hess 和 Aich 依靠统计分布与可控大尺度条件，而不是逐样本回归真值。

同为“8 倍”或“16 倍”，三者的信息量和可实现误差不等价。项目对照不能只写空间倍率，还应公开粗输入构造、时间配对和偏差处理。

### 时间建模存在四个层级，当前文献并未覆盖完整时空超分辨

- **独立快照**：Addison、DPDM、CorrDiff、DiffScaler、Hess、Aich 的主模型。即便时间自相关有所改善，也不是显式轨迹建模。
- **多帧条件、单帧输出**：Merizzi 用四个粗时刻预测一个细时刻；TAUDiff 的均值模块读取序列，但最终目标仍是序列末端场。这类方法能利用时间上下文，却没有输出整段高分辨率随机轨迹。
- **联合短片生成**：STVD 同时生成五帧残差，最接近真正的时间一致性学习，但输入输出都保持 3 小时间隔。
- **大规模独立气候状态采样**：cBottle 的全球 5 km 结果展示空间可扩展性，其主任务并非由低时间采样序列恢复同一时段内更密的高分辨率场。

所以，把“使用视频网络”或“输入多帧”直接称为时间超分辨是不准确的。十篇论文共同留下的空白正是：由**粗空间且稀疏时间的输入**生成**细空间且更密时间的联合条件分布**。

### 潜空间和 patch 是不同性质的近似

LDM_res 的 VAE 在潜在表示中压缩空间维，误差下界可由“真值编码再解码”单独测量；其结果明确显示小尺度谱损失可来自解码器而非扩散。cBottle 和 DPDM 的 patch 主要解决显存与全局生成规模，但引入重叠和边界一致性问题。CfC 若放在潜空间中，应先报告重构上限；若用于跨 patch 状态传播，则还需检验是否把局部边界误差带入后续时刻。

### 极端评估必须从像素尾部走向事件与影响

多分位误差、R95p 和功率谱是必要但不充分的。CorrDiff 的台风最大风速半径揭示“总体风谱正确但风暴几何错误”；TAUDiff 的风暴计数开始接近事件频次；Aich 的重现期、Rx1Day 和 CDD/CWD 将统计尾部连接到影响；cBottle 的分类器引导则提供主动过采样稀有事件的路线。可靠结论应同时说明强度、位置、持续时间、事件次数和集合覆盖率，而不是只报告一张极端个例图。

## 对本项目的启示

### 模型设计：把 CfC 放在条件时间轴，而不是盲目替换扩散去噪器

建议以正式 CorrDiff 为不可省略的锚点，逐步增加时间结构：

1. **CfC 条件均值**：用实际时间间隔 \(\Delta t\) 驱动 CfC 编码粗分辨率序列，输出各目标时刻的条件均值；地形、海陆和位置编码继续作为静态空间条件。这样保留 CorrDiff 已验证的均值/残差分工，也直接利用 CfC 对连续时间和不等间隔输入的表达能力。
2. **CfC 条件化的逐时刻残差**：共享原扩散去噪器，只把 CfC 隐状态作为额外条件。这是成本较低的第一版，但独立残差噪声仍可能造成帧间抖动，应视为弱时间模型。
3. **联合残差序列**：让 CfC 状态跨目标时刻传播，并在残差噪声或去噪条件中显式耦合相邻时刻，接近 STVD 的联合分布目标。该版本才应被用来检验“时间超分辨”，而非仅检验多帧输入是否有益。
4. **潜空间作为后续分支**：只有在像素空间 CfC-CorrDiff 对照成立后，再引入 LDM_res 式压缩，并预先报告 VAE 的 RMSE、极端分位和谱重构上限。

默认不建议让模型自回归消费自己刚生成的高分辨率场作为主要路径；这会把均值误差、残差采样误差和长时间漂移混在一起。先让 CfC 传播低维条件状态，更容易归因，也更适合从稀疏观测时刻重建中间时刻。

### 物理增强：约束应作用于有物理意义的变量和尺度

- 风场可采用 TAUDiff 的散度、涡度和平流相关损失，但需做无量纲化和分变量权重消融。
- 锋面可检查温度梯度、跨锋风切变与雷达回波的位置共现，延续 CorrDiff 的个例诊断。
- 雷达反射率不是守恒变量，不能直接套用降水或质量守恒损失；若要做水汽/降水守恒，需要相应物理通道和可靠单位转换。
- 借鉴 Hess/Aich 的尺度控制，把可信粗尺度保留写成显式上采样一致性检查；同时避免过强约束把随机残差再次压成确定性平滑场。
- cBottle 的谱分析提示应检查训练噪声范围是否覆盖 CWA 场的大尺度方差，但这属于数据适配，不需要在本主题展开通用采样器优化。

### 对照实验：把“均值时间化”“残差时间化”和“潜空间化”分开

在相同训练时刻、输入通道、静态条件、集合成员数和去噪预算下，建议至少保留：

| 对照 | 时间均值 | 残差生成 | 回答的问题 |
| --- | --- | --- | --- |
| 插值 | 无学习 | 无 | 空间/时间插值的基本下限 |
| 单帧 U-Net | 无 | 无 | 确定性空间映射 |
| 原版 CorrDiff | 无 | 独立单帧扩散 | 项目正式空间基线 |
| CfC-UNet | CfC | 无 | 时间上下文本身贡献多少 |
| CfC-CorrDiff（弱） | CfC | 独立逐帧、CfC 条件 | 仅时间化均值是否足够 |
| CfC-CorrDiff（联合） | CfC | 跨时刻耦合残差 | 随机小尺度时间一致性是否进一步提升 |

附加消融应包括输入长度（如 1/3/5 个粗时刻）、真实 \(\Delta t\) 与等间隔假设、是否使用未来帧、是否使用静态地形，以及是否加入物理损失。若做业务预报只能使用过去帧；若做同时段重建可使用中心窗口，但必须明确标注，不能混用两种信息条件。

训练/验证划分应防止重叠窗口跨集合泄漏。除现有 205 时刻空间基线外，应建立 2021 年连续留出片段，并单独预留台风、锋面和强降水片段。对时间增密任务，训练时可用完整高分辨率序列监督中间时刻，推理时只保留稀疏粗输入；评价必须区分“输入已有时刻的重建”和“未输入中间时刻的插补”。

### 评估：按五个正交维度组织，而不是堆一个总分

1. **逐点与集合**：单成员和集合均值 MAE/RMSE、fair CRPS、spread-skill、rank histogram；成员数固定并报告有限集合修正。
2. **空间结构**：分变量 RAPSD、空间自相关、粗尺度上采样一致性、patch/区域边界误差。
3. **时间结构与联合概率**：时间功率谱、滞后自相关、相邻帧差分分布、传播速度；逐时刻 CRPS 只评价各时刻的边缘分布，不能检验轨迹联合性。对联合样本另用 energy score、标准化 variogram 类评分和多时刻 rank histogram，并与单变量偏差、谱和对象指标互补，避免逐时刻边缘指标掩盖轨迹不连续。
4. **极端事件**：强降水/反射率分位误差、R95p/Rx1Day（时间尺度允许时）、重现期、风暴次数；台风另报强度、路径/中心位置和最大风速半径。
5. **物理与外部真实性**：风温雷达跨变量共现、散度/涡度诊断；有合适站点或雷达观测时，增加独立观测验证，不只对 WRF 真值评分。

CfC 的价值应由“在保持 CorrDiff 空间谱和极端分数的同时，显著改善时间指标”来证明。若只有 MSE 改善而谱、spread 或极端变差，应判定为回归平滑收益，而不是完整的时空生成进步。

## 优先阅读顺序

1. **`mardani-2025-corrdiff`**：先固定项目数据、任务和残差扩散基线。
2. **`srivastava-2024-video-diffusion`**：理解联合残差序列、时间上下文消融和分布指标。
3. **`sundar-2024-taudiff`**：对照另一种时序均值 + 轻量残差路线，并提取物理损失设计。
4. **`tomasi-2025-latent-diffusion`**：评估潜空间扩展的收益及 VAE 误差下限。
5. **`addison-2022-local-scale`**：回到条件扩散降尺度的基本假设与静态位置条件。
6. **`aich-2026-conditional-diffusion`**：设计真实模式输入下的偏差、极端和集合校准实验。
7. **`ling-2024-probabilistic-reconstruction`**：补充大区域、多变量、长时段和 patch 工程视角。
8. **`brenowitz-2025-cbottle`**：了解 CorrDiff 之后的全球公里尺度、噪声谱设计与极端引导。
9. **`hess-2025-scale-adaptive`**：在非配对和跨 ESM 场景需要可控尺度迁移时重点阅读。
10. **`merizzi-2024-wind-speed`**：实现 sequence-to-one 和站点外部验证对照时阅读。
