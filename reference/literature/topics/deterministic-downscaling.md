# 深度学习确定性统计降尺度：方法演进与项目启示

## 范围与问题

本主题关注用机器学习把低空间分辨率、必要时低时间采样率的天气或气候场映射到高时空分辨率场，覆盖随机森林、CNN、UNet、单图像超分辨网络及 GAN 在降水、气温、风场和太阳辐照中的应用。CorrDiff 及扩散模型不在本主题内。这里保留 GAN，是因为它们构成了确定性回归方法演进中的关键对照，并最清楚地揭示“逐点最优”与“分布/物理结构真实”之间的差别；但 GAN 的随机采样能力不应被误称为确定性预测。

十篇论文实际上对应三类不可混用的任务：

1. **同一数据源粗化—复原**：从高分辨率场构造低分辨率输入，如 DeepSD、PhIRE、Leinonen 等和部分 Harder 等实验。它适合隔离超分辨能力，但粗化算子会给模型提供很强的先验。
2. **跨数据源或跨模式映射**：输入与目标存在模式偏差，如 YNet 的 GCM→PRISM、Höhlein 等的 31 km→9 km 预报和 Baño-Medina 等的 perfect prognosis。它更接近实际降尺度，却同时混入偏差校正。
3. **时空重建**：不仅补空间细节，还恢复未采样的中间时刻，以 Serifi 等最直接；Leinonen 等只增强已有各时刻的空间分辨率，Harder 等则给出两种任务的组合架构。

因此，对本项目而言，核心不是寻找一个普遍“最强网络”，而是明确粗化机制、时间条件、变量统计特性和评价目标后，判断 CfC 的连续时间表示是否带来独立增益，CorrDiff 的生成能力又是否在均值场之外改善可信的高频分布。

## 方法演进脉络

**从局部非线性回归到空间归纳偏置。** He 等的 Prec-DWARF 已证明邻域粗网格降水、地形和干湿距离能非线性恢复细尺度降水，但树模型没有显式二维场生成先验。DeepSD 的堆叠 SRCNN 把卷积权重共享、多尺度地形和逐级放大组合起来，奠定“天气场即多通道图像”的工程范式。随后 Baño-Medina 等的重要性不在提出更复杂网络，而在用 VALUE 指标和暖期留出说明：卷积带来的自动空间特征提取常比盲目加深网络更重要。

**从浅层 SRCNN 到多尺度融合和变量专用架构。** YNet 与 DeepRU 分别代表编码器—解码器、跳跃连接、静态高分辨率辅助场融合在气候投影和矢量风场中的成熟。两者的结果同时否定了“只要换 UNet 就全面获胜”：YNet 的优势建立在月尺度 MSE 上，DeepRU 则必须与表现不弱的线性集成比较，且风向、风速需要分别衡量。Serifi 等进一步把变量频率特性引入结构选择——缓慢温度可借三线性插值再学残差，快速降水若沿用不可靠的时间插值基线，残差学习反而失败。

**从条件均值到高频分布与时空状态。** MSE 回归倾向输出条件均值，因而平滑并压低极端值。PhIRE 用对抗损失改善能谱和湍流统计，却付出更高逐像素 MSE；Leinonen 等加入 ConvGRU，使高频实现能沿序列一致演化，并用 CRPS 和 rank 统计检查集合，而不是用“更锐利”代替可信度。Rampal 等把两条路线重新组合：UNet 先预测可确定的期望状态，cGAN 只生成残差，再用区域最大强度约束稳定对抗训练。这一路线与本项目“确定时空骨干 + 生成细节”的关系尤其直接。

**从软物理惩罚到可证明的输出约束。** Harder 等把粗细网格均值一致性写成网络最后一层的确定性变换，而不是只向损失添加罚项。其意义是把物理要求从“训练时鼓励”提升为“推理时保证”，并覆盖 CNN、GAN、ConvGRU 和时间插值架构；同时也明确展示了错误约束会传播粗场偏差。物理增强因此不是任意添加守恒正则项，而应从观测算子、变量单位和粗化定义出发。

**尚未闭合的连续时间问题。** 现有时间方法主要是固定间隔 ConvGRU、把目标时间作为标量条件的 CNN，或先做光流帧插值再做空间超分辨。它们都没有充分回答不规则采样、可变时间间隔和连续目标时刻查询。CfC 的潜在贡献应定位于这些缺口：以序列状态和实际时间间隔更新空间潜变量，再在任意目标时刻解码，而不是仅把 CfC 替换进网络后比较一个总 RMSE。

## 跨论文综合

### 1. 排名随任务和指标改变，不能从单篇结果继承“最优模型”

DeepSD、YNet 的逐点误差优势，PhIRE 的能谱优势，Leinonen 等的谱距离/集合优势并不矛盾。确定性 RCNN 可以在 RMSE 和 MS-SSIM 上胜过 GAN，同时丢失高频方差；GAN 可以改善分布和视觉结构，却把雨团放在错误位置。对本项目，若目标是危险天气场的实际重建，必须同时回答“是否复原了这一个事件”和“长期统计是否真实”，不能用一组指标掩盖另一组的退化。

### 2. 数据构造方式往往比网络名称更决定难度

同一高分辨率场平均池化得到的低分辨率输入，天然满足局部均值关系；真实 GCM/RCM、再分析/观测之间则有系统偏差、网格投影和不同物理过程。Harder 等在 NorESM 上的反例正说明，从合成粗化得到的结论不能直接迁移。跨论文的“倍率”也不可简单横比：50 倍 PhIRE、16 倍 Leinonen 和 8 倍 DeepSD 的输入信息、变量和时间尺度完全不同。

### 3. 静态辅助场有用，但不是无条件的免费信息

DeepSD、YNet、DeepRU 和 Serifi 等反复显示高程、陆海掩膜和地理坐标能帮助复杂地形重建；Höhlein 等的置换实验也显示地表粗糙度和边界层高度可能贡献很小。YNet 的月气候态适合长期映射，却可能在天气尺度将输出拉向平均态。项目应分别消融高程、陆海掩膜、坐标和气候态，不应把全部辅助通道作为固定配方。

### 4. 时间一致性、集合校准和物理守恒是三条不同轴线

序列看起来平滑不等于时间动力正确；rank histogram 平坦也不等于每个成员满足守恒；守恒同样不保证极端位置和强度正确。Leinonen 等的长序列伪影、Rampal 等的架构相关集合校准、Harder 等的错误约束反例共同说明，三者必须分别测试。CfC 的闭式状态更新可能改善第一条，但不会自动解决后两条。

### 5. 可靠验证需要分布外设计，而非随机切片

Baño-Medina 等的暖期测试、Leinonen 等的跨年份测试、Rampal 等的跨 GCM 测试分别检验时间、年份和模式结构变化。相反，随机裁剪 patch 的邻近样本可能共享同一天气过程，使泛化看起来过强。即使只做台湾区域，也应按完整事件和连续时间块切分，另留出台风、季风和暖期等压力测试。

## 对本项目设计、对照实验与评估的启示

### 模型设计

- **采用“共享空间骨干 + 可替换时间模块”的消融结构。** 在同一 UNet/超分辨解码器下比较：仅目标时间条件（Serifi 式）、ConvGRU（Leinonen 式）和 CfC。输入帧数、通道、参数量和训练预算尽量匹配，才能把增益归于连续时间状态。
- **把 CfC 的状态放在多尺度潜空间，而非只串接在输出图像后。** 粗尺度状态可描述天气系统平移和发展，细尺度分支负责局地地形响应；目标时刻应作为连续变量进入状态推进或解码，而不是离散帧号。
- **区分可预测均值与不可识别细节。** 可先训练确定性 CfC-UNet，再让生成模块学习残差；单样本评价与集合/分布评价分开报告。Rampal 的强度约束可作为生成残差的稳定性对照，但需检查它是否扭曲真实极端峰值。
- **按变量选择直接重建或残差重建。** 温度可保留三线性/双三次插值残差路线；降水至少设置直接重建分支。风场使用 U/V 分量并分别评价方向和模长，不宜只处理风速标量。
- **物理约束从粗化算子推导。** 对区域平均的非负累积量，可试验 AddCL/ScAddCL/SmCL；对温度等强度量，只有粗网格确为对应面积权重平均时才使用均值守恒。零降水格点、海陆边界和面积权重需显式处理，并保留无约束和软约束对照。

### 对照实验

1. **最低层**：最近邻、双线性/双三次、时间线性及三线性插值；这是所有增益的底线。
2. **经典统计层**：GLM/线性集成和 Prec-DWARF 式随机森林。随机森林可使用邻域粗场、高程、坐标、dry drift 与时间差，避免把深度模型只与过弱插值比较。
3. **空间深度层**：SRCNN/DeepSD、普通 CNN、UNet/YNet；在同一数据划分上比较，而非照抄原文数字。
4. **时间深度层**：时间条件 CNN、ConvGRU、CfC；另做“相同帧直接空间超分辨”的上界/下界，分离时间信息贡献。
5. **生成与物理层**：确定性模型、生成残差模型，以及各自有/无硬约束的版本。GAN 可作非扩散生成对照，但不与 CorrDiff 的专项文献和结论混在本主题内。

数据实验至少分成两组：一组用明确、守恒的粗化算子隔离超分辨能力；另一组使用真实跨分辨率/跨数据源配对检验部署偏差。训练、验证、测试按连续时间块和完整天气过程切分；增加跨年、跨季节、暖期和跨子区域测试。若评估 CfC 的特有主张，还应单独改变输入时间间隔、使用不等间隔帧和未见过的目标时刻，而不仅是固定倍率抽帧。

### 评估体系

- **基础误差**：RMSE、MAE、平均偏差、Pearson/Spearman 相关，按变量、季节、地形和强度分层。
- **降水发生与极端**：干湿分类/ROCSS、P98/P99、RX1Day、湿/干持续期、时间标准差比和强度直方图距离。
- **空间结构**：径向平均功率谱及 LSD/RALSD、variogram、FSS；这些指标可区分“平滑但 RMSE 低”和“纹理真实但位置错误”。
- **时间结构**：滞后自相关、事件到达/峰值时刻误差、中间帧误差随目标时间位置的变化、长序列漂移和伪影率。
- **风场矢量**：U/V 的 MSE、风向 cosine dissimilarity、风速偏差和 absolute relative error。
- **物理一致性**：粗细网格聚合残差、负值比例、质量/能量守恒违反量；约束模型同时报告精度，防止只证明“满足约束”。
- **生成集合**：CRPS、rank histogram、outlier fraction，并用最大池化 CRPS 缓解位置误差的双重惩罚；不能只挑视觉上合理的样本。
- **效率与稳定性**：训练成本、单帧/整序列推理成本、不同序列长度下的误差增长。DeepRU 的快速推理和 ConvGRU 的长序列伪影提示两项都应成为正式结果。

## 优先阅读顺序

1. **vandal-2017-deepsd**：先掌握超分辨降尺度的基本问题定义、堆叠 SRCNN 和经典对照。
2. **bano-medina-2020-intercomparison**：建立严谨的变量相关评价观，理解为什么更深网络不必然更好。
3. **serifi-2021-spatiotemporal**：直接进入与本项目最接近的时空重建、目标时间条件及温度/降水架构差异。
4. **leinonen-2021-recurrentgan**：重点读 ConvGRU 状态更新、长序列稳定性和 CRPS/rank 评价，为 CfC 对照设标。
5. **harder-2023-hardconstraints**：精读约束层的数学假设、FlowConvGRU 及 NorESM 反例，再决定物理增强实现。
6. **rampal-2025-reliablegan**：理解确定均值 + 生成残差、强度约束及跨 GCM 验证的近期组合方式。
7. **hohlein-2020-windfield**：用于风场、多尺度地形和矢量指标设计，也用于校准对 UNet 优势的预期。
8. **liu-2020-ynet**：补充真实 GCM→观测、多模型通道和高程/气候态融合做法。
9. **stengel-2020-phire**：重点读感知—失真权衡、能谱和湍流统计，而非只关注 50 倍数字。
