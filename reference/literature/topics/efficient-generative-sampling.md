# 高效生成采样：通用扩散/score 模型与低成本生成

## 范围与问题

本主题只讨论通用生成模型：扩散/score 基础、免训练少步采样、蒸馏与一致性模型、潜空间表示、patch/多尺度骨干及训练动力学。天气应用不在本批范围内。选文以能否转化为 CorrDiff+CfC 的明确设计或对照为准，而不是追求覆盖所有扩散分支。

对公里尺度、长时间窗口和多成员集合，推理成本可粗略拆为：

> **总成本 ≈ 扩散步数（NFE）× 单次时空网络成本 × 物理时间长度 × 集合成员数**，潜空间方案还要计入编码/解码成本。

因此“高效”至少有四类含义，不能互相替代：

1. **减少 NFE**：DDIM、EDM、DPM-Solver；进一步是一至少步蒸馏和一致性模型。
2. **降低单次 NFE**：LDM 压缩空间维度，DiT 调节 patch/token 与模型容量，轻量引导减少条件分支开销。
3. **降低训练与调参成本**：EDM2 的稳定训练与 post-hoc EMA；蒸馏则以额外训练换取长期推理收益。
4. **改善算力—质量分配**：DiT 表明增加采样计算未必能补偿骨干容量不足，不能只压缩求解器而忽略网络本身。

CfC 还需额外回答一个本文献没有直接解决的问题：连续神经状态沿**扩散噪声时间**、**天气物理时间**还是二者共同演化。若每个去噪步都运行完整时序模块，NFE 的下降会被逐步状态更新成本部分抵消；若跨物理时刻复用状态，又必须防止样本间状态泄漏和误差累积。

## 方法演进脉络

### 1. 从离散反向链到连续生成轨迹

DDPM 确立了“学习不同噪声层的去噪器，再反向迭代”的基本范式。score SDE 随后把离散链解释为连续 SDE，并给出共享同一 score 的反向 SDE 与 probability flow ODE：前者便于随机探索，后者提供确定性轨迹、可逆编码和专用 ODE 求解的入口。DDIM 则从非马尔可夫前向过程得到可跳步的隐式模型，其确定性形式也与 ODE 视角相接。

这条脉络对项目最重要的不是术语统一，而是把**模型学习目标**与**采样数值方法**分开：同一训练好的去噪器可换采样器，因而无需先重训就能开展公平、低风险的 CorrDiff 推理对照。

### 2. 从通用数值积分到扩散专用少步求解

DDIM 主要靠跳步降低调用数；EDM 系统重做 σ 参数化、预条件、时间离散和二阶 Heun，使“网络如何表达 score”与“积分器如何走轨迹”协同；DPM-Solver 再解析处理扩散 ODE 的线性部分，只近似神经网络的指数加权积分，以较少步获得高阶收敛。

效率提升因此不是简单地把步长调大，而是减少每步误差并合理安排噪声尺度。对天气场尤其要单独扫描低噪声区步长，因为视觉感知指标不敏感的小尺度误差，可能对应极端降水和谱尾能量误差。

### 3. 从免训练求解到训练摊销

渐进蒸馏以教师的两步指导学生一步，反复减半；一致性模型进一步学习整条 ODE 轨迹的端点映射，天然支持一步和多步。两者把成本从每次推理转移到训练阶段，适合作为高成员数、长时间窗口和稳定业务配置的候选方案，但不如 DDIM/DPM-Solver 即插即用。渐进蒸馏原论文的证据来自 CIFAR-10、ImageNet 64² 和 LSUN 128²；迁移到 CorrDiff+CfC 仍需重新验证天气质量、轨迹一致性和实际延迟。

这也形成清晰的项目决策点：若实验配置频繁变化，先用免训练求解器；若模型、区域、变量和时间步长已冻结且调用量足够大，再用蒸馏回收训练成本。

### 4. 从像素空间到潜空间、patch 与训练动力学

LDM 改变“在哪里扩散”，DiT 改变“用什么骨干扩散”，EDM2 改变“如何稳定训练和廉价调参”。它们与求解器近似正交，可组合但不能混为同一类收益。尤其 DiT 的结果提醒：总预算固定时，应在单步骨干容量与采样步数之间共同分配，而非一味追求一步生成。

## 跨论文综合

### 少步、确定性和集合多样性存在张力

DDIM、DPM-Solver、渐进蒸馏和一致性模型的主要加速路径都偏向确定性轨迹。对单样本 FID，这可能是优点；对 CorrDiff 的概率天气预报，却必须显式管理初始噪声、条件扰动与集合成员，不能把同一条件下一个确定性输出当作完整预测分布。EDM 的随机“churn”或 score SDE 的校正机制可作为多样性对照，但会增加步数和调参。

评估应同时看均值误差与分布质量。一步模型即使单样本清晰，也可能集合离散度不足；多步随机模型即使单样本 FID 稍差，也可能有更好的 CRPS、spread-skill 和极端事件覆盖。

### 训练免费与训练摊销不是替代关系，而是阶段关系

DPM-Solver 适合在任何已训练 CorrDiff 上快速建立质量—NFE 曲线，并帮助挑选教师轨迹。只有当少步求解器仍不能满足延迟预算时，才值得投入渐进蒸馏或一致性训练。教师也应先通过天气指标筛选，否则蒸馏会高效复制教师的系统偏差。

对 CfC，蒸馏对象应是**联合时空生成过程**：逐帧独立学生可能保住单帧 RMSE，却破坏时间连续性。教师轨迹、CfC 隐状态初始化和跨窗口边界都要纳入训练样本定义。

### 表示压缩与少步求解可乘法组合，但误差也会叠加

LDM 降单次成本，DPM-Solver/一致性模型降调用次数，二者组合最有希望支撑大区域长时集合。然而自编码器先丢失的极端值无法靠更多扩散步恢复；少步求解又可能进一步平滑细节。因此应做“像素教师 → 潜空间学生”和“潜空间教师 → 少步学生”的分阶段消融，定位误差来源，而不是直接比较两个同时改变多因素的系统。

### 单步成本、步数和模型容量需要联合预算

DiT 的扩展实验和 EDM2 的轻量引导共同说明，NFE 不是完整成本指标。条件引导可能使每步接近两次前传；patch 变小会增加 token；CfC 会增加状态读写和时序依赖。反之，较大的骨干可能用更少步达到同等质量。最终应报告实测延迟、吞吐、显存与训练 GPU 小时的 Pareto 前沿，而不是只排名 NFE 或 FID。

### 图像基准与天气时空超分辨之间仍有明确证据缺口

这 10 篇主要以静态自然图像验证方法，LSUN/ImageNet 上的 FID、IS 或 Gflops 不能证明动力一致性、极端降水可靠性或跨时刻稳定性。潜空间重建、少步离散化、一致性训练和 patch 化都可能优先损害稀有高值与高频谱尾。因此本文献提供的是可检验的机制与实验方法，不是天气性能结论。

## 对本项目的启示

### 设计建议

1. **先固定 EDM 基线再接入 CfC。** 将 σ 采样、预条件、损失权重、随机性和 Heun 步进拆成独立开关；避免把求解器改进、CfC 时间记忆和物理约束混在一次实验中。
2. **明确 CfC 的两种时间轴。** 分别实验“每个物理时刻独立去噪、CfC 只跨物理时刻传状态”和“CfC 同时参与去噪轨迹”的方案；记录状态初始化、重置、窗口边界和反向传播截断规则。
3. **推理加速分三级实施。** 第一级为同一 checkpoint 上的 EDM/DDIM 与适配后的 DPM-Solver；第二级为潜空间或 patch/token 降成本；第三级才是渐进蒸馏和一致性模型。这样每一级都有可回退的精度基线。
4. **潜空间优先检验重建上界。** 在任何扩散训练前，单独报告 autoencoder 对各变量、极端分位数、谱和空间梯度的重建误差；若不达标，不应以扩散补救表示瓶颈。
5. **低成本采用 EDM2 的两个独立思想。** post-hoc EMA 可几乎不改动生成目标地减少重复调参；轻量无条件引导可单独测试。幅度保持层则作为骨干改造实验，不与 CfC 首发版本捆绑。
6. **物理增强与一致性训练分开命名。** ODE 轨迹自洽是生成器约束，不是天气方程约束；物理守恒、变量闭合和时间因果仍需独立损失或评估。

### 对照实验矩阵

- **求解器消融**：固定模型、条件、初始噪声和输出分辨率，对 EDM 原采样、DDIM 类确定性跳步、DPM-Solver 扫描 NFE；适用时再比较随机校正。NFE 可覆盖高步参考至少步区间，但各方法必须使用相同天气样本和成员数。
- **时间模块消融**：固定骨干容量、训练预算和求解器，比较无时间模块、普通时序卷积/循环与 CfC；额外比较独立帧、窗口内共享状态和跨窗口传状态，分离“时间建模收益”和“推理缓存收益”。
- **表示与骨干消融**：像素空间与多个潜空间压缩率、不同 patch 大小分别比较；记录解码器和 patch 合并成本，防止只统计扩散主体。
- **训练摊销消融**：用同一高质量教师比较免训练少步、渐进蒸馏、一致性蒸馏；报告达到目标质量所需总训练 GPU 小时，以及多少次集合推理后才能抵消额外训练成本。
- **EDM2 消融**：post-hoc EMA、轻量引导和幅度保持层分别开关，观察它们是否与 CfC 的状态幅度漂移相互作用。

### 评估协议

- **质量**：分变量、区域、季节和提前期报告 RMSE/MAE、偏差、CRPS、集合 spread-skill 与可靠性；不要以 FID 作为主天气指标。
- **时空结构**：报告功率谱/谱尾误差、空间梯度、时间差分误差和跨帧相关性；检查少步或蒸馏是否以过平滑换取平均误差。
- **极端与物理**：针对高分位和阈值事件报告偏差、检出与漏报，并检查质量/水汽等适用守恒关系和变量间物理一致性。指标须与具体变量定义匹配。
- **效率**：同时给 NFE、单样本与批量延迟、吞吐、峰值显存、编码/解码开销、条件引导前传数、训练/蒸馏 GPU 小时；长窗口和集合场景报告总成本。
- **可比性**：固定验证样本与初始噪声做配对比较，使用多个训练种子估计波动；发布质量—延迟—显存 Pareto 曲线，并保留高步教师作为参考而非假定其无误。
