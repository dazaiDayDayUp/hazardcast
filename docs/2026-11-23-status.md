# 项目交接

更新于 2026 年 11 月 23 日。

项目研究公里尺度区域天气场的时空超分辨，同时提高空间分辨率和时间采样频率。实现方向是结合 CorrDiff 和 CfC，并探索物理增强。当前处于第一阶段，正在建立 CorrDiff 的同一时刻空间降尺度基线和实验流程。

## 当前状态

- **环境**：`hazardcast` Conda 环境已配置 Python 3.12 和 PyTorch CUDA 12.9。GPU 1 已通过 CUDA 运算和 CorrDiff 模型验证。安装步骤及 PhysicsNeMo 提交见 [README](../README.md)。
- **数据**：本机通过 `data/cwa_dataset.zarr` 软链接只读访问 2018–2021 年的台湾 CWA 数据。[205 个评估时刻](../configs/experiments/corrdiff-validation-times.yaml)均有有效 ERA5 和 WRF 配对。
- **流程**：已用真实数据跑通回归训练、残差扩散训练、集合采样和指标计算。另用候选全尺寸权重完成了一个时刻、4 个成员、18 步去噪的验证。配置和指标见 [CorrDiff 实验记录](2026-11-23-corrdiff.md)，本机产物在 `runs/corrdiff-smoke/` 和 `runs/corrdiff-pretrained-check/`。
- **全量评分**：已对已有的 205 时刻、每时刻 32 成员的预报独立重算分数。与已有评分一致，和论文表 1 仍有差异，其中雷达及气温的重算 CRPS 较高。结果在 `runs/corrdiff-paper205-rescore/`，对照表见实验记录。
- **权重核验**：已核对 NVIDIA NGC 第 1 版发布包。服务器已有权重的回归张量与发布版一致。扩散权重的共有张量一致，发布版保留噪声尺度的位置编码，服务器版本使用零嵌入。发布权重保存在 `pretrained/corrdiff-ngc-v1/`，已在 `runs/corrdiff-official-check/` 完成首个时刻的试跑。
- **测试**：4 项自动测试通过，覆盖阶段执行、产物检查、集合指标和评估时刻。项目约定见 [AGENTS.md](../AGENTS.md)。
- **版本管理**：项目根目录已初始化本地 Git 仓库。VS Code 和 PyCharm 在主项目中仅显示根仓库，CfC 和 PhysicsNeMo 保留各自的 Git 历史。

## 本机重跑

在项目根目录执行。已有数据软链接时可直接运行，其他检出目录按 README 接入数据。

```bash
conda activate hazardcast
python -m unittest discover -s tests -v
python scripts/run_experiment.py configs/experiments/corrdiff-smoke.yaml --gpu 1
```
